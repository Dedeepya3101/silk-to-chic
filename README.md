# MatchO 👗

### AI-Assisted Saree Transformation & Local Tailor Discovery

MatchO connects people with unused sarees to local tailors who can transform them into modern, traditional, or personalized outfits.

It combines AI-assisted style discovery, tailor matching, real-time communication, and a structured request workflow into one platform.

---

## 🎯 Problem

People often have unused sarees but don't know:

- What outfit can be created from them
- Which style suits the saree
- Which tailor can make it
- Which tailor is reliable

Local tailors also have limited digital visibility and depend heavily on offline customers.

---
