# Saree Style Studio

Build a modern startup-style web application prototype called “MatchO”.

====================================================

ABOUT MATCHO

====================================================

MatchO is a fashion-tech platform that connects users who own sarees with nearby tailors who can redesign those sarees into modern outfits.

Users upload saree images and describe what they want.

Nearby tailors browse those saree requests and send professional redesign suggestions such as:

- long frocks

- short frocks

- kurtas

- gowns

- lehengas

- crop-top sets

- indo-western dresses

- custom outfits

The platform DOES NOT include online payments.

The app only connects users and tailors safely.

After online discussion and agreement, both parties meet offline for stitching.

The app should feel like:

- a modern AI startup

- fashion-oriented

- elegant

- trustworthy

- mobile-first

- clean and premium

====================================================

MAIN USER TYPES

1. USER

People who upload sarees and want redesign ideas.

2. TAILOR

Tailors who browse saree requests and suggest dress transformations.
